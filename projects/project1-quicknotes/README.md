# QuickNotes

QuickNotes is a simple note-taking web app built with plain HTML, CSS and JavaScript.

## Features

- Add notes with Personal, Work, or Study categories
- Validate empty notes and the 200-character maximum
- Search notes as you type
- Delete individual notes
- Clear all notes with confirmation
- Save notes in localStorage
- Show notes newest first
- Responsive layout for phones and larger screens

## How to Run Locally

1. Clone this repository:
   `git clone https://github.com/yourtechbaddie-ke/web-foundations-days.git`
2. Open `projects/project1-quicknotes/index.html` with Live Server.
3. Use the form to add, search, delete, and clear notes.
